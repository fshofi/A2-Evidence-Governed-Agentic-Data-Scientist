# A2 Technical Objection Register

| Objection | Evidence-based answer | Remaining boundary |
|---|---|---|
| “This is just logistic regression.” | The model is deliberately interpretable. A2's contribution is the governed evidence-to-action workflow, not algorithmic novelty. | No claim of novel statistical learning. |
| “Why use old banking data?” | It is public, pinned, reproducible and contains a clear temporal-admissibility trap. | It cannot evidence current banking performance. |
| “An ordered split is not temporal validation.” | Correct. It is stronger than shuffling this stated date-ordered file, but exact timestamps and prospective data are unavailable. | No prospective-validation claim. |
| “AUC 0.748 is not enough for deployment.” | Correct. A2 calls it bounded retrospective ranking value and withholds action. | Operating sufficiency is unresolved. |
| “The probabilities are miscalibrated.” | Correct. V1.1 exposes ECE 0.093 and maximum bin error 0.321. | Prospective recalibration is required. |
| “The 1:5 cost ratio is arbitrary.” | It is an explicitly illustrative sensitivity input; `selected_threshold` remains null. | Real cost, harm and capacity criteria are absent. |
| “These are not fairness tests.” | Correct. They are labelled subgroup stability diagnostics with small-group suppression. | No equality, causal, legal or fairness conclusion. |
| “A human approval flag is not governance.” | Correct by itself. It demonstrates state separation and audit visibility; it grants no external permission or execution power. | Real identity, role, policy and revocation controls are future integration work. |
| “Why call bounded services agents?” | They have explicit roles, inputs, outputs and failure states, coordinated through a shared run state. Determinism makes the control path inspectable. | No claim of general autonomous reasoning or LLM swarm behaviour. |
| “A proxy heuristic can miss leakage.” | Correct. It catches exact, deterministic and near-perfect proxies and fails closed on identified cases. | Semantic provenance and domain review remain essential. |
| “Was this independently validated?” | No. It was clean-environment reproduced and adversarially tested with AI assistance. | Independent human validation remains a later gate. |
