# A2 Portfolio Pack

Start with these artefacts:

1. `../output/pdf/A2_Client_Case_Study.pdf` — polished two-page client handout.
2. `CASE_STUDY.md` — full client-facing proof narrative.
3. `A2_ARCHITECTURE_PLATE.svg` — presentation and LinkedIn visual.
4. `dashboard-preview.png` — verified preview of the evidence surface.
5. `DEMO_SCRIPT.md` — 90-second and five-minute walkthroughs.
6. `COMMERCIAL_WORDING.md` — CV, LinkedIn, recruiter and proposal copy.
7. `TECHNICAL_OBJECTIONS.md` — adversarial interview and reviewer preparation.
8. `RELEASE_MANIFEST.md` — frozen release identity and non-claims.
9. `PUBLICATION_AUDIT.md` — final security, evidence and claim review.

The public technical entry point remains the repository root `README.md`. The definitive limitations and governance boundaries remain `LIMITATIONS.md` and `GOVERNANCE.md`.

The PNG previews are already included. To regenerate them, install `requirements-portfolio.txt` and run `python scripts/render_portfolio_previews.py`.
